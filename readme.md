# guenton.com

Personal site for GuenTon. Built with Svelte 5, SvelteKit 3, Skeleton 5, Tailwind 4, and TypeScript 6.

## Requirements

- Node.js 22.17 or newer

## Develop

```bash
npm install
npm run dev
```

## Check

```bash
npm run check
npm run lint
npm run build
```

`npm run preview` serves the production build locally. Do not use it as the production host.
